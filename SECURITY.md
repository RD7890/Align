# Security Policy

## Supported Versions

Only the latest release of Align receives security updates.

* **Latest Release (`v1.0.x`)**: Supported
* **Older Versions**: Not supported (please update to latest)

---

## Reporting a Vulnerability

If you discover a security vulnerability or privacy concern within Align:

1. **Do not open a public issue.**
2. Use GitHub's **Private Vulnerability Reporting** directly on the repository via the Security tab.
3. Alternatively, report by emailing `rd7890@users.noreply.github.com` with:
   - Description of the vulnerability
   - Steps to reproduce or proof-of-concept
   - Impact assessment
4. We will acknowledge receipt within 48 hours and work with you on a patch prior to public disclosure.
